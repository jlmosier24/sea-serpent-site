Load team records

On SwimTopia, open the team's Team Records page, save it (File, then Save Page As), and drop the saved page here. Events, times, years, and record holders are read; holders show only here, never on public pages. A record set at a meet imported here stays when it's faster than the page's.

Records set this season

For records set at meets imported before the records were loaded. Each record from this season is matched to the Spotswood swim or relay with exactly its time, which then gets the Team record tag, the Record Breaker badge, and its meet's record pill. Safe to run again.
